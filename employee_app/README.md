# ManPowerLink — Employee & Worker Flutter App

The dedicated mobile application for temporary workforce, field contractors, and daily-wage helpers.

## Quick Commands to Run & Build APK

```bash
# 1. Navigate to the employee app folder
cd employee_app

# 2. Install Flutter packages
flutter pub get

# 3. Run the app on emulator or physical phone
flutter run

# 4. Build release APK for testing or Google Play
flutter build apk --release

# Built APK output location:
# build/app/outputs/flutter-apk/app-release.apk
```

## Features
- **Nearby Shift Radar (25km)**: Live feed of dispatched jobs filtered by distance and skill matching.
- **Instant Acceptance**: Reserve shifts with guaranteed hourly wages.
- **Site Arrival Verification**: Workers enter the 6-digit OTP received from the employer on site.
- **One-Tap Clock-In**: Start and stop shift timers directly on phone.
- **Escrow Wallet & Payouts**: Daily earnings ledger with instant UPI withdrawal.
