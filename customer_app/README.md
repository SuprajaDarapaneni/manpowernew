# ManPowerLink — Customer & Employer Flutter App

The dedicated mobile application for business employers, contractors, and warehouse managers to hire on-demand verified workforce.

## Quick Commands to Run & Build APK

```bash
# 1. Navigate to the customer app folder
cd customer_app

# 2. Install Flutter packages
flutter pub get

# 3. Run the app on emulator or physical phone
flutter run

# 4. Build release APK for testing or Google Play
flutter build apk --release

# Built APK output location:
# build/app/outputs/flutter-apk/app-release.apk
```

## Features
- **Instant Shift Posting**: Select trade category, headcount (1–20), shift duration (4h, 8h, 12h), and site location.
- **Dynamic Escrow Breakdown**: Worker pay + platform fee calculation.
- **Site Arrival OTP**: Automatically generates and displays a 6-digit OTP to verify arriving workers.
- **Live Shift Tracking**: Real-time worker allocation counter and shift progress monitoring.
- **Escrow Settlement**: One-tap completion releases payouts from platform escrow.
